# Identifique no código:
classe: seria a forma de onde eu possso colocar as funções ( true ou false, cadastrar , etc ) 

objeto: é uma instancia da classe, a criação de um objeto a partir da classe

atributos: caracteristicas de um objeto 

métodos: ações que a classe vai fazer
